# sshm v0.2.0

*Released 2026-11-20 — host key verification, hardening, `~/.ssh/config` import/export, and a TUI that remembers where you were. First release published on GitHub.*

## Highlights

- **Host keys are verified.** Until now sshm accepted any server key, so a
  man-in-the-middle could collect the passwords of password hosts. sshm now
  uses `~/.ssh/known_hosts` exactly like `ssh`: new hosts show their
  fingerprint and need a `yes`, changed keys are refused with a full warning.
  Hosts you already reach with `ssh` are already trusted.
- **Bring your `~/.ssh/config` in.** The first run offers to import it (and
  every file it includes); `sshm import-ssh` does it any time. Each source file
  becomes a folder, hosts already in the vault are skipped, and key paths and
  port forwards come along. Passwords are not involved.
- **…and take your hosts out.** `sshm export-ssh` writes
  `~/.ssh/config.d/sshm.conf` so plain `ssh <alias>` works too — without a
  single password or passphrase in it — and offers to add the one `Include`
  line `~/.ssh/config` needs.
- **The master password once per login session** (Linux): the derived key is
  cached in the kernel session keyring. `sshm lock` forgets it,
  `sshm passwd` changes the password.
- **Search everything below the current folder** with `/`, sort with `s`,
  reveal a password with `ctrl+r`.

## Fixed

- **Folder passwords could be bypassed.** `p` removed a folder's password
  without asking for it; cancelling a delete prompt let the next unlock of
  another folder open "Delete <first folder>?". Changing a password now always
  asks for the current one, and every folder action carries its own prompt.
- **Deleting a folder could leave hosts behind** — invisible, but still in the
  vault with their passwords — when a subfolder was stored before its parent.
- **The vault is always private.** It was written through a fixed temporary
  name that could keep wider permissions; it now goes through a random
  temporary file with mode `0600`, synced before the rename.
- **Connecting no longer hangs**: 15 s timeout, `ctrl+c` cancels, dead
  connections are detected by a keepalive.
- IPv6 hosts and tunnels; tunnels that fail to start are reported; a remote
  shell exiting non-zero is no longer "Connection failed"; the first key
  pressed after a session is no longer lost; a damaged vault no
  longer crashes sshm; modals are centered on any terminal width.

## Changed

- The first run asks for the master password twice.
- After a session you are back in the same folder, on the same host, with the
  same search; unlocked folders stay unlocked.
- Install with `go install github.com/master2sid2/sshm@latest`.

## Upgrade notes

- Vaults from 0.1.x open unchanged.
- The first connection to each host asks you to confirm its fingerprint,
  unless you already connected to it with `ssh`.
